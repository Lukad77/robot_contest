# 简历项目描述 · 智能工厂送件服务机器人系统

> 项目名称建议：**智能工厂送件服务机器人系统**（百度智能云智能服务机器人赛参赛项目）
>
> 技术栈关键词：ROS 1 / catkin / C++ / AMCL / Gmapping / Hector SLAM / move_base / DWA / robot_pose_ekf / MoveIt! / YOLOv3 NPU / STDR 仿真 / RPLidar / Qt + RViz

---

## 完整版

### Bullet Points

- **独立搭建基于 ROS 1 的移动机器人全栈软件系统**（3 个 catkin 工作空间、20+ 功能包），集成 RPLidar 激光雷达、IMU、相机与串口机械臂等多传感器/执行器驱动，通过 EKF 融合轮式里程计与 IMU 解决单一里程计漂移问题，并基于 STDR 仿真器构建"仿真验证 → 真机部署"的一键切换开发闭环（launch 参数化切换），显著缩短现场调试周期；

- **实现建图-定位-导航完整 pipeline 并完成竞赛场景工程化调优**：采用 Gmapping/Hector 双 SLAM 方案建图，AMCL 蒙特卡洛定位，基于 move_base + DWA 局部规划实现多目标点连续导航（自研 MultiNavi 多点导航调度），针对比赛场地对 costmap 膨胀半径、导航超时、恢复行为等参数系统性调优，并开发 Qt + RViz 上位机实现地图采集与导航点位可视化标注、XML 持久化；

- **完成"视觉引导机械臂抓取"手眼协同全链路**：将 YOLOv3 目标检测模型部署至 NPU 边缘端加速推理，设计多帧检测确认策略抑制单帧误检；基于检测结果做目标相对位姿估算，驱动 Talon 六轴机械臂（MoveIt! 运动规划 + 自研串口驱动）配合底盘 PID 位姿微调完成零件抓取与放置，最终以业务状态机（导航→需求确认→视觉搜索→抓取→送达→结算→语音播报）串联全流程，在比赛环境下稳定跑通端到端任务。

### 项目描述段落

面向"智能工厂送件"竞赛场景，独立设计并实现了一套覆盖**仿真、建图、定位、导航、视觉识别、机械臂操作、语音交互**的服务机器人完整软件系统。系统基于 ROS 1 + catkin 构建，按应用层（业务状态机）、机器人套件层（驱动/导航/SLAM）、仿真层（STDR）三层解耦，含 20+ 功能包。底层完成 RPLidar 激光雷达、IMU、相机、串口机械臂等多传感器与执行器的驱动集成，采用 robot_pose_ekf 扩展卡尔曼滤波融合轮式里程计与 IMU 提升位姿估计鲁棒性；建图定位采用 Gmapping/Hector SLAM 构建先验地图、AMCL 蒙特卡洛算法实时定位；导航基于 move_base 框架（全局 A*/Dijkstra + DWA 局部动态避障），并自研 MultiNavi 多点导航调度实现按订单连续送件。感知端将 YOLOv3 部署至 NPU 边缘加速推理，结合多帧检测确认策略实现零件的可靠识别与定位；操作端通过 MoveIt! 运动规划驱动 Talon 六轴机械臂，配合底盘 PID 闭环位姿微调完成视觉引导下的抓取与放置。业务层以有限状态机串联"导航取件 → 需求确认 → 视觉搜索 → 机械臂抓取 → 送达结算 → 语音播报"端到端流程，全部关键参数（导航超时、PID、取件距离、补扫策略）集中于 launch 配置便于现场快速调参；同时开发 Qt + RViz 建图标注上位机用于点位标定，并借助 STDR 二维仿真器实现无硬件条件下的全流程回归验证与真机/仿真一键切换。

## 精简版

### Bullet Points

- 独立搭建 ROS 1 全栈机器人系统（20+ 功能包）：多传感器驱动集成、EKF 里程计融合、STDR 仿真与真机一键切换；
- 落地建图-定位-导航完整 pipeline：Gmapping/Hector 建图 + AMCL 定位 + move_base/DWA 多点连续导航，完成竞赛场景参数调优；
- 实现视觉引导机械臂抓取：YOLOv3 NPU 边缘部署 + 多帧检测确认，MoveIt! 驱动六轴机械臂配合底盘 PID 微调，以状态机串联端到端送件流程。

### 项目描述段落

基于 ROS 1 独立开发的智能工厂送件服务机器人，覆盖仿真、建图、定位、导航、视觉识别、机械臂操作、语音交互全链路。采用三层 catkin 架构（业务/驱动导航/仿真）；Gmapping 建图 + AMCL 定位 + EKF 传感器融合，move_base/DWA 实现多目标点连续导航；YOLOv3 部署至 NPU 加速推理并以多帧确认保证识别可靠性，MoveIt! 驱动 Talon 六轴机械臂完成视觉引导抓取；业务状态机串联"导航取件 → 视觉搜索 → 抓取 → 送达结算 → 语音播报"端到端流程，支持 STDR 仿真与真机一键切换，在比赛环境下稳定跑通全流程。
