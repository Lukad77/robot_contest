- 每个 ROS package 均遵循标准结构：include/、src/、launch/、CMakeLists.txt、package.xml 齐全，并通过 `<depend>` 声明显式依赖。
- Nodelet 插件通过 `robot_plugins.xml` 注册，sensor 与 motion controller 均继承自 base class（sensor_base.h、motion_controller_base.h）以实现多态加载。
- GUI 组件采用 Qt Designer 的 *.ui 文件配合 C++ 代码分离，资源图标统一放在 resources/images/ 并通过 images.qrc 管理。
- Launch 文件使用 include 组合方式复用组件（如 server_with_map_and_gui.launch 依次 include robot_manager、stdr_gui），避免重复配置。
