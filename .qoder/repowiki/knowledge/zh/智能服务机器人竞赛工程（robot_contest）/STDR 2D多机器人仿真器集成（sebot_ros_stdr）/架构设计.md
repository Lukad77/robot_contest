该模块是 fork 自 stdr-simulator-ros-pkg 的完整 STDR 仿真生态，按 catkin package 拆分为多个职责清晰的子包：
- `stdr_msgs`：定义所有 msg/srv/action 接口（RobotMsg、LaserSensorMsg、CO2Source、SpawnRobot.action 等），作为其他包的公共契约。
- `stdr_server`：仿真核心节点，通过 `stdr_server_node.cpp` 启动 Server，负责地图加载、机器人生命周期管理与传感器同步。
- `stdr_robot`：以 nodelet 插件形式实现机器人本体与传感器（laser/sonar/co2/rfid/sound/thermal），由 `robot_plugins.xml` 动态加载。
- `stdr_gui`：基于 Qt4 的可视化界面，包含 sensors、map_metainformation、robot_creator、visualization 四个子目录，通过 UI 文件（*.ui）描述界面。
- `stdr_parser`：XML/YAML 解析器，支持机器人、传感器、噪声模型等资源的序列化与验证。
- `stdr_resources`：预置地图（frieburg/hospital_section/mines/robocup/simple_rooms）、传感器 XML 模板、机器人配置文件。
- `stdr_launchers`：提供 server_with_map_and_gui.launch 等组合 launch 文件，一键启动仿真环境。
- `stdr_amcl` / `stdr_hector_mapping` / `stdr_navigation` / `stdr_move_base`：对第三方 SLAM/导航栈的参数与 launch 定制。
依赖方向：gui → server + robot + parser；server → robot(nodelet) + parser + resources；robot → parser + msgs；navigation/mapping 仅消费 msgs。
