模块为独立catkin包，采用Qt GUI + ROS通信的双层架构：
- 入口 `src/main.cpp` 创建 `QApplication` 并实例化主窗口 `SLAM`（继承 `QWidget`），以模态全屏方式运行。
- UI层由 `ui/slam.ui` 和 `ui/addtopics.ui` 通过 Qt Designer 生成，`include/slam.h` 定义主窗口类，包含 RViz 嵌入、话题管理、定时器与 XML 读写逻辑。
- 通信层 `include/qnode.hpp`（`QNode` 继承 `QThread`）封装 ROS 节点初始化、订阅/发布（如 `geometry_msgs/PoseStamped`、`nav_msgs/Odometry`）、多点导航目标发送等，通过 Qt 信号槽与 UI 解耦。
- RViz 集成通过 `include/qrviz.hpp` 的 `QRviz` 类实现，支持 Display Tree 模型交互、YAML 配置的导入导出。
- 数据持久化使用 `resources/location.xml` 存储工作台/取件台/起始点/结算区四类位置的位姿，路径通过 launch 参数 `/sebot_marking/pathXml` 注入。
- 依赖方向：main → SLAM → QNode/QRviz/AddTopics，不反向依赖；tinyxml 作为第三方 XML 解析器内嵌于 `src/tinyxml*`。
- 构建由 `CMakeLists.txt` 通过 `QT5_WRAP_UI`/`QT5_ADD_RESOURCES`/`QT5_WRAP_CPP` 自动处理 .ui/.qrc/.moc，链接 `roscpp`、`rviz`、`cv_bridge`、`image_transport` 等 catkin 依赖。
