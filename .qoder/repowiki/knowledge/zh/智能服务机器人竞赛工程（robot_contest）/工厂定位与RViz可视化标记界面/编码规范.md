- UI 与逻辑分离：所有界面布局通过 `.ui` 文件设计，头文件中仅保留 `Ui::XXX *ui` 指针及槽函数声明，构造函数中调用 `ui->setupUi(this)` 初始化。
- ROS 通信封装在独立的 `QNode` 线程类中，通过 Qt 信号槽（如 `sendMultiNaviGaols()`）与 UI 层异步通信，避免阻塞 GUI 事件循环。
- RViz Display 类型通过 `m_mapRvizDisplays` 映射表集中管理，键为显示名称（如 "Grid"、"LaserScan"），值为 `RVIZ_DISPLAY_*` 枚举常量，新增类型需同时添加映射项。
- 配置文件读取统一通过 `ros::param::get` 获取 launch 传入的参数（如 `/sebot_marking/pathXml`），而非硬编码路径。
- 资源文件通过 `.qrc` 清单（`images.qrc`、`media.qrc`）统一管理图标与媒体资源，CMake 中通过 `QT5_ADD_RESOURCES` 自动生成 C++ 源码。
