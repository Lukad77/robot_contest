模块按职责划分为两个子目录：
- `include/`：纯头文件形式的共享库，被同工作空间内其他节点直接 include 使用。其中 `arm.hpp` 封装 Talon 类通过 libserial 与 `/dev/talon` 串口通信，定义 USB 帧协议（帧头 0x42、累加校验、长度 4~30 字节）及关节/姿态/动作组等控制接口；`camera.hpp` 基于 Linux V4L2 ioctl 枚举 `/dev/video*` 并匹配 Astra Pro / USB 2.0 Camera / PC Camera A4 等设备；`detection.hpp` 封装 Detection 类，组合 Paddle PPNCPredictor（NNA+NMS）与 ONNX Runtime Session，完成图像预处理→NNA 推理→ONNX post 处理→NMS 后处理的完整流水线；`json.hpp` 与 `tinyxml.hpp` 为内嵌的 nlohmann/json v3.9.1 与 TinyXML-2.6.2 单头库；`tools.hpp` 提供 PID/PD 控制器、时间戳、语音播报等通用函数。
- `res/`：运行时数据资源，`model/` 与 `inference/` 存放 Paddle 部署包（deploy_paddle.tar/.ro/.params、config_ppncnna.json、io_paddle.json、label_list.txt、post.onnx、nms.tar），`image/` 存放 UI/标注图片，`location.xml` 用 TinyXML 描述工作台、取件台、起始点、结算区位姿。
依赖方向单向向下：业务节点 → 本模块头文件 → 系统库（libserial、v4l2、opencv、onnxruntime_cxx_api、paddle predictor）。
