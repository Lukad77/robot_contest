- 单元测试入口采用 `#include "../src/<node>.cpp"` 直接包含源码的方式实例化类，而非链接编译后的库，便于快速修改和调试。
- 所有控制参数通过 `ros::param::get("/sebot_<node>/...", ...)` 从 ROS parameter server 读取，PID 参数统一按 kP/kI/kD 三段命名。
- 主循环使用 `ros::Rate(loop_rate)` 配合 `ros::spinOnce()` 和 `loop_rate.sleep()` 实现固定频率轮询，状态机通过 bool run 标志位控制单次任务执行。
- 场景切换通过 ros::param 读取整数 sencePick 或字符串 food 来动态选择行为分支，避免硬编码。
