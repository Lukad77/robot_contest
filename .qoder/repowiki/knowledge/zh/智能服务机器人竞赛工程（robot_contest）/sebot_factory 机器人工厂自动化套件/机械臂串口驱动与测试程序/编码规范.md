- 所有串口命令统一构造 buff[帧头][地址][长度][数据...][校验和] 格式，校验和为前 N-1 字节累加和对最后一字节赋值。
- float 参数通过 Bit32Union 联合体逐字节写入 buff，保证与下位机一致的 IEEE754 内存布局。
- 每个公开 API 开头检查 isOpen 标志，未打开串口直接返回，避免空指针异常。
- 动作执行采用异步反馈模式：调用 setActions() 后通过 actionOver[action] 标志位轮询完成状态，而非阻塞等待。
- 错误处理统一使用 try/catch 捕获 libserial 的 ReadTimeout、NotOpen、OpenFailed 等异常，并打印 cerr 或 ROS_ERROR 后返回负码。
