本模块是一个独立的catkin包（sebot_marking），采用Qt5 + ROS混合架构：
- 入口 `src/main.cpp` 创建 QApplication 并启动模态主窗口 SLAM。
- 核心视图类 `SLAM`（`include/slam.h`/`src/slam.cpp`）继承 QWidget，封装 RViz 嵌入（`QRviz`）、ROS 通信（`QNode`）、话题管理（`AddTopics`）和 XML 位置持久化。
- 三层结构清晰：UI 层由 `ui/*.ui` 生成，业务逻辑集中在 `SLAM` 类，底层 ROS/RViz 交互通过 `qnode.hpp`、`qrviz.hpp` 抽象。
- 资源管理：`resources/images.qrc`、`resources/media.qrc` 打包图标与媒体；`location.xml` 存储工作台、取件台、起始点、结算区等位置坐标。
- Launch 文件 `sebot_marking.launch` 启动 map_server 加载预建地图，并通过 `<param name="pathXml">` 注入 XML 路径供运行时读取。
- TinyXML 直接解析 XML 配置文件，无需额外依赖。
