本模块由两个独立的 catkin 包组成：
- sebot_speech：ROS Python 节点 sebot_audio.py 订阅 /audio 话题（std_msgs/String），根据文件名从 res/audio/match/ 或 res/audio/sound/ 目录加载对应 .mp3 并通过 pygame.mixer 播放；CMakeLists.txt 通过 pkg_check_modules 链接 ALSA 库，launch/sebot_audio.xml 以 respawn=true 启动节点。
- sebot_visions：纯 Python 脚本包，sebotCollection.py 作为入口，组合 joyStick.py（pygame.joystick 多手柄热插拔识别 BD2A/BD4A/SW02）与 sebot_speech/scripts/uart.py（串口通信），通过 cv2.VideoCapture("/dev/deepCamera") 采集 640×480 图像并保存到 res/images/sample/。
依赖方向：sebot_visions 通过 sys.path.append 直接 import sebot_speech 的 uart.py，形成跨包脚本级耦合；两个包均无 C++ 源码，仅声明 catkin 依赖。
